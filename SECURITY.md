# Security

The current 0.1 series is supported. This program runs locally and has no network
code or telemetry. Inputs are data and are never executed. It is not a sandbox;
run on stable files in a directory you control. Do not use it on device files or
concurrently replaced paths. Reports omit payload text but still reveal counts
and positions. Converted output, when supported, contains the original data.

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/KanadeK/codec-transit/security/advisories/new).
If that form is unavailable, open an issue requesting a private reporting channel
without including exploit details or sensitive inputs. Do not post secrets.
